# Hemant Sharma — DevOps Portfolio

GitHub Pages-ready personal portfolio for Hemant Sharma, Senior DevOps Engineer.

## Files
- `index.html` — portfolio structure/content
- `styles.css` — visual design and responsive layout
- `script.js` — animations, reveal effects and counters
- `Hemant-Sharma-Resume.pdf` — downloadable resume

## GitHub Pages
1. Extract this ZIP.
2. Upload all four files to the root of `hemantssharma/hemantssharma.github.io`.
3. Commit the changes to `main`.
4. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
5. Open: `https://hemantssharma.github.io/`

Do not upload the ZIP itself if you want GitHub Pages to serve the site; upload the extracted files.
